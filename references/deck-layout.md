# 演示稿版式：页型、网格与字号

这一篇是**与内容和主题色解耦**的通用版式库。换主题色不用改这一篇；换题材也不用改这一篇。只改「内容」和「accent 色值」两处。

---

## 一、画布与网格

| 项 | 值 |
|---|---|
| 画布 | 1280 × 720（16:9，投影标准） |
| 左右边距 | 60px |
| 内容区宽度 | 1160px（1280 − 60×2） |
| 页眉带 | top 60px，高 34px（编号块 + 英文眉标） |
| 主标题区 | top 108–196px |
| 内容区 | top 200–630px |
| 页脚带 | top 660px（左侧来源 + 右侧页码） |

**两栏布局的标准切分**（内容区 1160）：
- 图文对半：左 578 + 间隙 32 + 右 550
- 左文右图：左 644 + 间隙 36 + 右 480
- 双卡并排：左 565 + 间隙 30 + 右 565

间隙用 30–36px，不要用 24 以下的窄缝，也不要用 48 以上的大缝（会在投影上显得散。

---

## 二、字号阶梯（投影可读性档）

演示稿和网页的字号逻辑不同：**投影后排至少 3 米**。所以下限更高、跳跃更大。

| 层级 | 字号 | 用在 |
|---|---|---|
| 封面字标 | 96px（Saira Black 拉丁） | 封面英文/数字 |
| 封面中文主标 | 64px | 封面标题 |
| 巨型数字 | 150–205px | 高潮页的数据展示 |
| 页面主标 | 40px | 每页标题 |
| 卡片小标 | 26–30px | 卡片标题、编号块 |
| 正文 | 20–24px | 段落正文 |
| 字段 / 眉标 | 16–17px | 英文眉标、字段、来源行 |
| **下限** | **16px** | 任何东西不得小于此值 |

**层级跳跃规则**：相邻两级至少差 3px，主链（主标 → 小标 → 正文 → 字段）至少差 4px。

正文字号定档后，**不要在局部单独放大或缩小** —— 层级关系一旦乱了，页面就没有主次。唯一的例外是巨型数字页（展示页规则：超大实心字标 + 空心字标 + 空心大编号）。

**内容密度参考**：一页正文 150–250 字是投影的舒适区。少于 100 字显得空，多于 280 字后排看不见。

## 三、颜色角色

| 角色 | 值 | 用在 |
|---|---|---|
| 纸 `paper` | `#F4F4F2` | 页面底 |
| 板 `panel` | `#FFFFFF` | 卡片、表格行 |
| 墨 `ink` | `#161616` | 正文、标题 |
| 次级 `ink2` | `#5C5C5C` | 说明文字、字段 |
| 细线 `rule` | `#D9D9D6` | 1px 分区线 |
| 浅块 `chip` | `#E4E4E0` | 空态块、次级底 |
| **强调 `accent`** | 主题色 | 只做填充 |
| **满版底 `deep`** | accent 的深派生 | 高潮页底色 |
| **`fore`** | accent 上的文字色 | 引擎决策 |

**墨色页的次级文字**用 `#A3A3A3`（压在 `#161616` 上约 5.4:1），不能用 `ink2`（`#5C5C5C` 在墨底上只有 2.6:1，看不见）。

强调色永远只做填充，不做线、不做字（浅底上 accent 作字要 4.5:1 以上才允许，见 `theme-accent.md`）。

---

## 四、页眉页脚规范（全篇一致）

**页眉**：左上角 `No.01` … `No.10` 强调色块（白字/墨字按 `fore` 决定）+ 右侧 `//` 英文眉标。

英文眉标是中文标题的直译（`// THIRTY SILENT YEARS` / 「三十年」）。**禁止用 `in` / `IN` 等词**——slidep 解析器会把独立词 `in` 当成 JS 运算符，导致眉标折行（详见 `pitfalls.md`）。

**页脚**：左下角来源标注（新华社 / 官网 / 数据出处），右下角页码 `01 / 10`。

## 五、九种通用页型

### 1. 封面 Cover

**用在**：第一页。

**构图**：左栏文字（眉标 → 字标 → 中文主标 → 副标题 → 一句话导语），右栏整幅照片（人物/产品/场景）。

- 眉标组：`No.01` 色块 + `//` 英文
- 字标：拉丁 96px（Saira Black）或中文 64px
- 副标题：26px 次级色
- 导语：21px 两三行
- 右图占 40–46%，满高

**禁忌**：不要在封面正文里写「本 PPT 用的全部是真实照片」这类元信息 —— 那是给自己看的，不是给观众看的。

### 2. 导语 Thesis

**用在**：封面之后、正文之前，立一个论点。

**构图**：大引文或一句话论点（28–32px），下方 2–3 段支撑（24px），或一栏文字 + 一栏空镜图。

**禁忌**：不要把论点写成标题。论点要能独立成立，不依赖上一页。

### 3. 要点列表 Points

**用在**：最常见的正文页。

**构图**：编号条（`01`/`02`/`03`，Saira 900，26px）+ 小标（22px 粗）+ 一行说明（20px），行间 1px 细线。

**关键约束**：一行高度必须容得下「小标换行 + 说明两行」。若小标会换行，宁可把标题缩短也不要压行距（本次实战踩过：行高 66px 装不下 24px 标题的换行，导致下一行被压）。

**禁忌**：条目超过 5 条就拆页。

### 4. 时间轴 Timeline

**用在**：有明确年序的内容。

**构图**：竖排时间轴（年份 + 事件）或横排节点。年份用 Saira 900 宽体数字，事件 20–24px。

**关键约束**：每一行是固定高度容器（40–46px），年份列定宽（84px），标题列定宽（310px 左右），说明列自适应。行高算错会裁掉最后一行。

**禁忌**：不要用不等宽的年份列，也不要让事件描述跨行挤压。

### 5. 数据看板 Metrics

**用在**：有一两个关键数字要砸出来。

**构图**：大数字（100–160px）+ 下方标签（18–20px）+ 一行解释。或左右两栏「数字 + 释义」。

**关键约束**：大数字和它的标签必须成组，不能让两个数字各自带一段说明（那样读者会把说明配错）。

### 6. 双栏对比 Split

**用在**：两个概念、两种选择、付出与收获。

**构图**：左右等宽卡片（565 + 30 + 565），一深一浅或一白一深。卡片高度一致。

**关键约束**：**两张卡的内容量要匹配**。一深一浅时，深色卡上的文字必须是浅色（`#FFFFFF` / `#A3A3A3`），浅色卡上是墨色。深色卡在墨底上写 `ink2` 会看不见。

**禁忌**：不要一张卡塞三段、另一张塞一行。

### 7. 引言金句 Quote

**用在**：情绪转折或章节收束。

**构图**：居中大字（32–44px）加署名，或一条强调色短线引文（见 p4 的做法）。

**禁忌**：一页只放一句金句 + 一点上下文，不要塞成文字墙。

### 8. 高潮页 Climax

**用在**：整套片子的峰值，通常是第 3–4 页和倒数第二页。

**构图 A（左色右浅）**：左侧深色面板（480px）承载巨型数字（150–205px）或主视觉，右侧纸底放引文与说明。**强调色占比 37.5%**。

**构图 B（满版图）**：整幅图片压上强调色调，左侧文字区加暗层，底部题诗。

**关键约束**：满版图的文字必须落在**压暗区**上；题诗类文字用**绝对定位**锚在页脚上方，不要用流式布局（流式布局下题诗会压住来源行和页码 —— 本次实战踩过）。

**禁忌**：不要在满版页上同时出现满版强调色和满版图片，两层重色会互相削弱。

### 9. 收尾 Closing

**用在**：最后一页。

**构图**：满版图 + 一句结语（32–46px 白字）+ 落款/日期。

**禁忌**：不要只写「谢谢」。结语要回扣开头的论点。

## 六、演讲备注（notes）

每页都写**第一人称逐字讲稿**，供照读使用：

- 长度 120–300 字，约 60–90 秒口播
- 用「各位好」「接下来我们看」这类自然连接词，不要念标题
- 数据、日期、人名要念全，不能只说「这一页的数字」
- 写完念一遍，卡壳的地方就是要改的地方

**不要在 notes 里写「本 PPT 用的是真实照片」这类元信息** —— 那是给自己看的，不是给观众听的。如果有观众问起，如实说明来源即可。

## 七、通用骨架

```jsx
<Slide notes={`第一人称逐字讲稿……`} style={{
    width: 1280, height: 720, background: '#F4F4F2', flexDirection: 'column',
    fontFamily: 'Noto Sans SC', padding: 60,
}}>
    {/* 页眉 */}
    <Box style={{ flexDirection: 'row', alignItems: 'center', gap: 16, height: 34 }}>
        <Box style={{ width: 62, height: 30, background: 'ACCENT', flexDirection: 'row',
            alignItems: 'center', justifyContent: 'center' }}>
            <Text style={{ fontFamily: 'Saira', fontSize: 16, fontWeight: 700,
                color: 'ACCENT_FORE', letterSpacing: 1 }}>No.01</Text>
        </Box>
        <Text style={{ fontFamily: 'Saira', fontSize: 16, fontWeight: 700,
            letterSpacing: 2.6, color: '#5C5C5C' }}>// SECTION TITLE</Text>
    </Box>

    {/* 主标题 + 贯通细线 */}
    <Text style={{ fontFamily: 'Noto Sans SC', fontSize: 40, fontWeight: 700,
        color: '#161616', marginTop: 14 }}>中文标题</Text>
    <Box style={{ width: 1160, height: 1, background: '#D9D9D6', marginTop: 12 }} />

    {/* 内容区：高度必须算准 */}
    <Box style={{ flexDirection: 'row', gap: 32, marginTop: 26, height: 420 }}>
        ...
    </Box>

    {/* 页脚 */}
    <Box style={{ flexDirection: 'row', justifyContent: 'space-between',
        alignItems: 'center', marginTop: 'auto' }}>
        <Text style={{ fontFamily: 'Noto Sans SC', fontSize: 16, color: '#5C5C5C' }}>
            资料来源：XXX</Text>
        <Text style={{ fontFamily: 'Saira', fontSize: 16, color: '#5C5C5C' }}>01 / 10</Text>
    </Box>
</Slide>
```

**占位符约定**：DSL 里写 `'ACCENT'` / `'ACCENT_DEEP'` / `'ACCENT_FORE'` 等占位符，构建期由 `build_deck.py --accent` 统一替换。这样一套 DSL 能换任意主题色，不用改源文件。

## 八、交付前的版式自检

- [ ] 每一页都归到上面九种页型之一（混用两种页型的标题风格是常见翻车点）
- [ ] 最小字号 ≥16px，层级跳跃 ≥3px
- [ ] 内容区高度算得准，没有溢出、裁切、跨行压行
- [ ] 强调色只做填充；满版页的比例在 `accent_gen.py` 给的上限内
- [ ] 深色底上的文字是浅色，不是 `ink2`
- [ ] 页眉编号块、页脚页码全篇位置一致
- [ ] 英文眉标是中文标题的直译，且不含 `in` / `IN`
- [ ] 每页 notes 写完并念过一遍
