### 1.3 每个方案的脾气（选型说明）

**T1 亮黄 `#FFFA00`** —— 原 skill 的默认强调色，也是本案例的起点。

- 结构特点：浅底 + 墨底高潮页，黄色只做小块（编号块、短横线、图注数字）。
- 硬约束：黄色作字压纸底只有 **1.01:1**，**绝对不能拿黄色写正文**；accent 上只能压墨字（16.31:1）。
- 深红页/墨底页里的黄色装饰线是可用的（15.85:1），这是原 skill 视觉语言的核心。
- 适用：科技感、警示感、年轻化主题。
- 不适用：庄重的人物宣讲、追思、纪念 —— 亮黄偏轻快。
- **换色时的坑**：原 skill 把黄色写死在 DSL 里（`#FFFA00`），逐页手改极易漏；本包的正确做法是源文件写 `'ACCENT'` 占位符，构建期统一注入。

**T2 国旗红 `#C8102E`** —— 标准中国红，识别度最高。

- 白字压红 5.88:1 过 AA，但没过 AAA(7:1)；红字压纸底 5.34:1 也只是 AA。
- 面积上限压到 **25%**：白字在红底上只有 5.88:1，字号必须 ≥24px 且全白。
- 适合：党政、国庆、赛事等需要强识别的场合。

**T3 深中国红 `#A62B1F`** —— 本案例采用，**唯一「一色两用」全达标**的一档。

- 白字压红 **7.03:1**（AAA）、红字压纸底 **6.38:1**（AA）—— 同一个红既能当块底又能当正文色。
- 面积上限 **40%**，可以正经做高潮页。
- 气质：庄重、有年代感、有碑文味，配深红底照片染红非常稳。
- **本案例就是它**：`黄旭华-照读PPT-红主题终稿.pptx`。

**T4 暗红 `#8C1A11`** —— 最沉稳的一档。

- 白字压红 9.25:1、红字压纸底 8.40:1，两项都过 AAA。
- 代价：偏暗、缺透气感；大面积铺容易显旧。
- 适合：纪念、追思、碑文感。

**T5 任意色** —— 换色链路已验证：同一套 DSL 只改 `--accent`，面板底色、巨型数字、时间轴年份、引文短线全部跟随，accent 上的文字色由引擎按对比度自动决策。

```bash
python scripts/accent_gen.py "#1E88E5" --name 科技蓝   # 先算色板
python scripts/build_deck.py --slides slides/ --out deck.pptx --accent "#1E88E5"   # 再构建
```

**注意浅色 accent 的代价**：亮黄、科技蓝这类浅色 accent 的墨字压得住（16.31 / 4.92），但**作字压纸底不达标**，且**不能满版**。浅色 accent 适合「浅底 + 墨底高潮页」的结构；深色 accent 才能做「深红/深蓝满版高潮页」。

## 二、强调色页的版式方案（L 类）

一张页面里强调色铺多少，是全片视觉重心的关键决策。

| 方案 | 结构 | 强调色占比 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|---|
| **L1 左红右浅** | 左 480px 深色面板（巨型数字/引文）+ 右 800px 纸底（正文/时间轴/照片） | **37.5%** | 气势与可读性兼得；正文始终在纸底上 | 横向空间被吃掉，左侧内容要精炼 | 高潮页、成绩页 |
| **L2 上红下浅** | 上半部深色，下半部纸底 | 38% | 章节分隔感强，像"翻页" | 横向切割，画面重心偏上 | 章节页、时间轴页 |
| **L3 浅底红块** | 纸底为主，强调色只做小块 | 17% | 最克制，阅读压力最小 | 没有高潮感 | 数据页、陈述页 |

**通用规则**：满版铺色会把强调色的「醒目」含义稀释掉，等于没有强调色。**高潮页留 1–2 张，其余页回到纸底。**

> 本案例里用户明确要求「第四页不要全红」，最终采用 **L1 左红右浅**，红占 37.5%，且巨型数字 186px 白字压在左侧面板上。

## 三、底色策略方案（B 类）

同一张满版照片，三种处理方式：

| 方案 | 做法 | 效果 | 代价 | 适用 |
|---|---|---|---|---|
| **B1 深红高潮页**（采用） | 照片染红 + 深红满版底 + 白字 + 等高线换白版 | 主题感最强，照片与页面融为一体 | 需要额外做图片染色（`tint_assets.py`） | 高潮页、封底 |
| **B2 全浅底** | 图片缩为局部块，所有文字在纸底上 | 最易读，投影清晰度最高 | 冲击力弱，"大片感"没了 | 讲稿式长讲、需要边听边读 |
| **B3 浅蒙层** | 保留满版图 + 浅蒙层压暗 | 冲击与可读之间折中 | 整页发灰，红色主题感被稀释 | 折中场景 |

> 本案例采用 **B1**，但把满版页控制到 2 页（p6 深潜、p10 追思），其余 8 页回到纸底。

## 四、选型决策树

```
用户说「用红色」？
├─ 项目里有删除/危险/撤销语义？
│   ├─ 有 → 红色不能当强调色，跑 accent_gen.py --suggest 找替代色
│   └─ 无 → 红色可释放（必须在变体卡写豁免）
├─ 题材是庄重/人物/纪念？
│   ├─ 是 → T3 深中国红（默认）；更沉可用 T4 暗红
│   └─ 否（党政/国庆/赛事）→ T2 国旗红
└─ 用户要「科技感」/指定品牌色 → T5 任意色，先跑 accent_gen 看四组读数

强调色页怎么排？
├─ 用户说「不要满版」→ L1 左红右浅（默认）
├─ 用户说「要有气势」→ L1，但把面板加宽到 560px
└─ 用户说「我怕太花」→ L3 浅底红块

要不要深色高潮页？
├─ 整套 ≤8 页且要安静 → B2 全浅底
└─ 有 1–2 个情绪高点 → B1 深红高潮页（本案例）
```

## 八、禁忌

- 不要在一套片子里同时用两种强调色（包括"主强调色 + 红色点缀"）。
- 不要拿浅色 accent（黄/科技蓝）写正文 —— 实测 1.01:1 / 3.34:1，等于隐形。
- 不要在深色底上用 accent 画装饰线（深红在墨底 2.50:1），改白色。
- 不要为了"气势"把强调色铺满全页，先查面积闸。
- 不要凭目测对比度，全部读数由 `accent_gen.py` 出。
